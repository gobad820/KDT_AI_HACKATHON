## 4. 다른 컴퓨터에서 시작하기

1. 저장소를 받는다.

   ```bash
   git clone https://github.com/gobad820/KDT_AI_HACKATHON.git
   cd KDT_AI_HACKATHON
   ```

2. Python 3.11로 가상환경을 만들고 패키지를 설치한다.

   ```bash
   python3.11 -m venv .venv && source .venv/bin/activate
   pip install -r requirements-dev.txt
   python3 -m pytest
   ```

3. `cp .env.example .env`를 하고 `LLM_API_KEY=` 뒤에 자기 Gemini 키를 붙인다.
   - 경고: 키를 커밋, 채팅, 단체방에 올리지 않는다.
4. 배포하려면 `npx vercel login`으로 로그인하고 `npx vercel link`로 Vercel 프로젝트 `nammeun-don`에 연결한다. 배포 명령은 `npx vercel deploy --prod`다.
   - 경고: 환경변수는 Vercel 프로젝트 설정에 이미 있다. `vercel env`로 바꾸지 않는다.
5. 그 폴더에서 Claude Code를 켜고 아래 문장을 붙여 넣는다.

   ```text
   나는 김상해다.
   docs/status-2026-11-23.md를 읽고 1장의 상태를 다시 확인해서 보여 줘.
   그다음 3장 순서대로 진행하되, 각 단계는 내가 확인하면 시작해.
   ```
