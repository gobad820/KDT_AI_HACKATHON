## 1. 주제 후보 (11/20)

대회 규정상 문제 정의와 핵심 의사결정은 팀이 직접 해야 함. 아래는 Claude가 조사해 정리한 후보이고, 평가는 팀이 다시 할 것. 아이디어 탐색에 Claude를 쓴 사실은 AI 활용내역에 기재.

### 1-1. 선정 기준

1. 사용자가 청년이고 우리 셋이 직접 겪은 문제인가
2. 챗봇이 아니라 에이전트인가: 스스로 조회·판단·작성하는 단계가 2개 이상
3. 공공데이터·공개 API로 바로 데이터를 확보할 수 있는가(실제 개인정보 불필요)
4. 심사위원이 URL을 열고 3분 안에 결과를 볼 수 있는가
5. 기존 소재, 기존 서비스와 한 문장으로 구분되는가
6. 토·일 이틀 안에 핵심 흐름을 완성할 수 있는가 (D-3라 추가)
7. 주관 기관(대한상의)과 행사(청년과 기업을 잇는 박람회)에 접점이 있는가 (추가)

### 1-3. 후보 ① 첫 직장, 10년 뒤 경제력 (상세)

**한 줄 요약**: 채용공고 두 건을 넣으면 세후 월급, 근무지 주변 월세 실거래가, 근무 지역에 따라 달라지는 청년 세제까지 계산해 "어느 쪽이 얼마 더 남는지"와 "같아지려면 연봉을 얼마 받아야 하는지"를 근거와 함께 알려주는 에이전트.

**대상 사용자**: 수도권 공고와 지역 공고를 함께 보는 취업 준비 청년. (팀이 부울경에서 서울 공고도 같이 보는 입장이라면 직접 겪는 문제)

**문제**: 일자리를 연봉 숫자로만 비교함. 실제로 남는 돈은 세금·4대보험, 근무지 주변 월세, 지역 지원금에 따라 달라지는데, 이를 따지려면 실수령액 계산기, 부동산 앱, 정책 사이트를 따로 돌려 직접 계산해야 함.

**근거 통계 (소개서에 쓰기 전 원문 확인)**

- 대한상의 2025.6 「상반기 채용시장 특징과 시사점 조사」: 대졸 청년 구직자 희망 연봉 평균 4,023만 원, 신입 채용공고 평균 3,708만 원. 비수도권 취업 조건 1위 '높은 급여 수준' 78.9%. 대한상의는 연봉·복지·근무환경 정보를 데이터 기반으로 제공하는 채용정보 플랫폼의 필요성을 언급.
- 대한상의 2022.6 「지방근무에 대한 청년 인식 조사」(수도권 청년 구직자 301명): 지방 근무 기피 72.8%. 지방 근무를 택하는 데 필요한 추가 연봉은 '1,000만 원' 응답이 36.5%로 최다. 기피 이유는 네트워크 부재 60.7%, 생활·문화 인프라 59.8%, 주거·생활비 부담 48.9%.
- 중소기업중앙회 2026 조사(청년 1,000명): 비수도권 중소기업 취업에 필요한 조건으로 주거 지원 55.2%, 경쟁력 있는 임금 47.5%.
- 국가데이터처 2026.5 청년층 부가조사: 첫 일자리 평균 근속 1년 6.8개월, 퇴사 사유 1위 '보수·근로시간 등 근로여건 불만족' 44.4%.

**에이전트 흐름**

1. 공고 두 건(텍스트 붙여넣기)에서 연봉, 근무지, 복지(식대·기숙사·주거지원), 고용 형태를 추출
2. 빠졌거나 모호한 조건("연봉 협의", 근무지 미기재)은 사용자에게 되묻고, 추출 결과를 확인받음
3. 세후 월급 계산 도구 호출
4. 근무지 시군구의 원룸 월세 실거래가 조회 도구 호출. 표본이 적으면 기간이나 인접 지역을 넓힐지 스스로 판단
5. 근무지의 지역 유형과 감면 대상 여부를 판정해 청년 세제를 현행법·정부안 시나리오로 적용
6. 연간·누적 남는 돈 비교, 손익분기 연봉 역산
7. 결과를 근거·가정·범위와 함께 설명. 후속 질문("기숙사가 있으면?", "본가에서 통근하면?")에 다시 계산

**AI와 코드의 역할**

- AI: 공고 해석, 되묻기, 어떤 도구를 어떤 조건으로 부를지 결정, 정책 문구에서 적용 가능성 판단, 결과 설명
- 코드: 세후 계산, 월세 통계(중위값·범위), 보증금 환산, 손익분기 역산. 금액은 AI가 만들지 않음

**한계 대응 (AI 활용 5점 항목)**

- 추출한 연봉·근무지를 사용자가 확인·수정하는 단계
- 모든 금액 옆에 계산식과 가정(부양가족 수, 비과세 식대 등) 표시
- 월세는 단일 값이 아니라 범위(25~75%)와 표본 수·기간 표시
- 정책 지원금은 확정이 아니라 "신청 자격 확인 필요"로 표시
- 근거가 없는 항목은 "확인 불가"

**기존 서비스와 차이**

- 연봉 실수령액 계산기: 세후 금액만 제공
- 부동산 앱: 시세만 제공
- 알바천국 'AI 공고 비교 분석': 희망 근무조건과 공고 조건의 매칭률 비교
- 커리어리 소문 'AI 공고 비교': 공고에서 추출한 항목 비교
- 잡코리아 원픽 연봉 예측: 직무·경력별 예측 연봉
- 해외에는 도시별 생활비를 반영해 '같은 생활수준에 필요한 연봉'을 환산해 주는 계산기가 흔함(Indeed Flex, Expatistan 등). 국내에도 지역·주거 유형별 생활비 계산기가 있음(seoulstart)

**우리만의 기능: 지역 유형별 청년 세제 시나리오**

같은 연봉이어도 근무 지역과 회사 규모에 따라 달라지는 청년 세제를 공고에 대입해, 현행법과 개편안 시나리오별로 감면기간 누적 금액까지 보여주는 기능.

- 배경(원문 확인 필수): 재정경제부가 2026.8.3 발표한 「2026년 세제개편안」에 중소기업 취업자 근로소득세 감면의 지방 우대와 적용기한 연장이 포함됨(상세본 목차 45쪽).
  - 현행: 청년(15~34세) 5년간 90%, 연 200만 원 한도, 2026.12.31까지 취업분
  - 정부안: 1유형 수도권 5년 / 2유형 비수도권 광역시·수도권 우대지역 6년 / 3유형 기타 비수도권·비수도권 광역시 우대지역 7년 / 4유형 기타 비수도권 우대지역 10년. 적용기한 2029.12.31까지 연장, 2027.1.1 이후 취업분부터 적용

  - **정부안이고 국회 확정 여부는 11/20 기준 확인하지 못함.** 한도 상향 등 의원안도 여럿 계류. 세법은 통상 11월 말~12월 초에 국회에서 확정
- 왜 우리만의 것인가

  - 감면 대상인지 알려면 공고에서 회사 규모·업종·근무지를 읽어야 함 → AI가 필요한 지점

  - 비수도권 상공회의소들이 2026.8 국회에 비수도권 근로소득세 차등 법안 처리를 건의 → 주관 기관 네트워크의 관심사와 맞닿음

  3. 연간 결정세액 기준으로 감면액 계산(코드), 감면기간만큼 누적
  4. 주거비 차이 누적과 합쳐 "n년 누적 남는 돈"과 손익분기 연봉 제시
  5. 인사팀에 보낼 확인 질문 생성("중소기업 취업자 소득세 감면 신청이 가능한 회사인가요?")

  - 감면 대상 업종, 제외 대상자, 감면세액 계산식, 근로소득세액공제 조정식은 조세특례제한법 시행령 제27조에서 확인함(11/20, 국가법령정보센터). 정리는 계산 규칙 문서에 있고, 팀이 원문을 한 번 더 대조할 것

**MVP 범위 (이틀)**

- 화면 3장: 입력(샘플 공고 버튼 포함) → 추출 확인 → 결과
- 핵심 기능 3개: 공고 해석과 되묻기, 세후 계산 + 월세 조회, 지역 유형별 청년 세제 시나리오와 누적 비교
- 샘플 공고는 가상 회사로 직접 작성

**시간이 부족하면 빼는 순서**: 지역 정책 조회(온통청년) → 후속 질문 재계산 → 인접 지역 확장. 월세 API가 불안정하면 주요 시군구 값을 미리 받아 캐시(마감 전에 확정).

**미리 밝힐 범위**: 돈만 계산함. 대한상의 조사에서도 지방 근무 기피 이유 1·2위는 네트워크와 인프라였음. 커리어·생활 인프라는 범위 밖이라고 소개서에 적을 것.

**리스크**

- 세후 계산 정확도: 2026년 요율과 간이세액표를 공단·국세청 원문으로 확인, 공식 계산기와 대조 검증
- "계산기 아니냐"는 반론: 공고 원문 해석, 되묻기, 표본 부족 시 스스로 범위 조정, 후속 질문 재계산을 화면에 단계로 보여줄 것
- 월세 실거래가는 신고분 기준이라 최근 한 달은 누락 가능

**확장 계획 (확장성 5점 항목)**: 통근 시간·교통비, 지역 물가, 공고 주장 검증(후보 ②), 지역 상공회의소·지자체 일자리센터·기업 채용 페이지 연동

**신청용 아이디어 소개 초안 (433자, 선택 시 팀이 고쳐서 사용)**

> 수도권과 지역 공고를 함께 보는 취업 준비 청년은 연봉 숫자만으로 일자리를 비교합니다. 그러나 손에 남는 돈은 세금과 근무지 주변 월세, 그리고 근무 지역과 회사 규모에 따라 달라지는 청년 세제에 좌우됩니다. 정부는 2026년 세제개편안에서 중소기업 취업 청년의 소득세 감면기간을 지역에 따라 5~10년으로 차등하겠다고 밝혔지만, 청년이 자기 공고에 대입해 볼 방법은 없습니다. 본 서비스는 채용공고 두 건을 붙여넣으면 AI 에이전트가 연봉·근무지·회사 조건을 읽고 빠진 조건은 되물은 뒤, 세후 급여 계산, 국토교통부 전월세 실거래가 조회, 지역 유형별 감면 적용을 차례로 수행합니다. 결과로 현행법과 개편안 시나리오별 누적 남는 돈과 두 공고가 같아지는 연봉을 근거와 함께 보여줍니다. 금액 계산은 검증한 코드가 맡고, 확정되지 않은 제도는 시나리오로 구분해 표시합니다.

- 참가자 풀(KDT 훈련생)이 같아 경쟁 팀의 수준과 소재를 가늠하는 데는 유효. 3·4·8회 결과는 기사로 보완.

### 5-3. 수상 패턴 6가지

1. **타깃이 좁고 문제를 숫자로 증명.** RestArt는 "장애예술인 62%가 기본 생계 유지 곤란", New Direction은 "골든타임 확보율 57.4%", 수채화는 "청각장애인 의료통역 실질 지원 0.9%"로 시작.
2. **문제 → 기술 → 효과가 한 문장으로 이어짐.** 밥상일터: 소일거리 추천 → 보상 → 식사. 도로정찰대: 위성사진 → 노후 차선 탐지 → 정비 비용 절감.
3. **범용 챗봇은 본선에 가도 상위권은 아님.** 5회 GPT 민원 챗봇(OMG)은 본선 8팀 중 하위 5팀에 해당하는 우수상, 6회 RAG 보고서 생성·AI 면접 준비는 장려상. 상위는 고유 데이터·모델·워크플로가 있는 서비스.
4. **최근 최고상은 '업무를 끝까지 처리하는' 유형.** 8회 띠몬(기록 교차 확인 + 서식 자동 작성), 6회 최우수 SIGenie(선적지시서 자동 처리). 이번 주제 "AI 에이전트"와 같은 방향.
5. **사업화·현장 적용성이 심사평 단골.** 5회 "사업화 가능성 및 기술적 완성도", 4회 "상용화·창업 가능성", 8회 "추가 하드웨어 없이".
6. **1~6회는 사회적 약자 대상이 다수.** 이번 대회는 대상 사용자가 '청년'이라 이 서사를 그대로 가져오면 주제 적합성이 약해짐.

### 5-4. 이미 나온 소재 (차별성 감점 위험)

- 보이스피싱·금융사기 탐지(5·6·8회), 수어 번역·청각 보조(1·4·5회), 시각장애인 보행·길 안내(1·3회)
- AI 면접 준비(6회), 청년 자산관리(6회), 근로계약서 적법성 진단(8회 본선), 민원 챗봇(5회), 상황·감정 기반 음악 추천(3회 2팀)
- **소개서 양식에 예시로 적힌 소재**(공고 붙여넣으면 자소서·예상 질문 생성, 1인 가구 식비 관리)는 다른 팀이 그대로 따라 할 가능성이 높음
- **청년 정책 맞춤 추천**은 정부가 직접 만드는 중: 온통청년 AI 맞춤 연결 서비스 준비(2026.10 보도), 정부24 AI국민비서, 서울 청년몽땅정보통 AI 추천
- **공고 조건 비교**는 채용 플랫폼이 이미 제공: 알바천국 AI 공고 비교 분석, 커리어리 소문 AI 공고 비교

### 5-5. 이번 대회가 과거와 다른 점

- 예선부터 심사위원이 프로토타입에 직접 접속해 구현 수준을 확인. 링크를 열고 3분 안에 가치가 보여야 함.
- "AI 결과의 오류·불확실성 대응"이 예선·본선 모두 5점으로 명시. 준비한 팀이 확실히 가져가는 점수.
- 코드 대부분을 AI가 생성해도 출품 가능. 대신 팀이 문제 정의·설계·검증을 주도했고 작동 원리를 설명할 수 있어야 함.
- 단순 래핑 여부를 심사위원이 판단. 문제 정의·기능 설계·데이터 연계·워크플로·검증에서 팀의 기여가 보여야 함.

## 8. 제출 전 체크리스트

- [ ] AI 활용내역에 서비스용 AI와 개발용 AI 도구를 모두 기재
- [ ] AI가 만든 코드는 직접 실행·테스트, AI가 제시한 수치·출처는 원문 확인
- [ ] 오픈소스·데이터·이미지·폰트 라이선스 확인, 별첨 표에 기재
- [ ] 사전 개발 내역을 제출 설문과 소개서 별첨에 동일하게 기재(없으면 "해당 없음")
- [ ] 타 공모전·대회 출품·수상작과 유사하지 않음
- [ ] 외부 AI API에 실제 개인정보 미입력
- [ ] 코드·영상·발표자료에 API 키·비밀번호 없음
- [ ] 로그아웃 상태(시크릿 창)에서 프로토타입 링크 접속·실행 확인
- [ ] 12/7까지 버틸 사용량 한도·과금 설정
- [ ] 제출 링크 업로드 + 같은 자료 이메일 발송
- [ ] 대표자 참가 동의·서약서 제출
- [ ] 저장소에 마감 시점 버전 태그
