- 예선 심사 종료일(11/30)까지, 본선에 가면 12/7까지 서비스가 동작해야 한다.

## 위험과 되돌리는 법

- 동결 뒤에 버그를 찾으면 버그 수정만 합친다. 합칠 때마다 샘플 2쌍을 다시 확인한다.
- 배포가 깨지면 Vercel에서 직전 정상 배포로 되돌린다(메뉴 이름은 확인 필요).
- 마감 뒤에 허용되는 변경은 접속 복구, 인증정보 교체, 실행 환경 복구뿐이다.
- 마감 뒤에 금지되는 변경은 기능, 알고리즘, 프롬프트, 데이터다. 어기면 실격될 수 있다.
- Gemini 키 한도가 바닥나면 키를 바꾼다. 인증정보 교체라서 허용된다.
- `gemini-flash-lite-latest`는 별칭이라 12/7 전에 동작이 바뀔 수 있다. 어댑터는 실패하면 대체 모델 2개로 넘어간다.
- 마감 뒤 모델 교체는 기능 변경으로 볼 수 있다(확인 필요). 그래서 별칭을 고정 버전으로 바꿀지는 동결 전에 정한다(U-6).
- 태그는 push 전에 `git show`로 커밋을 확인한다. push한 뒤에는 지우거나 옮기지 않는다.
