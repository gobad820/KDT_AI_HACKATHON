## 시작하기 (처음 한 번, 15분)

1. GitHub 아이디를 단체방에 남긴다. 김상해가 저장소 협업자로 초대한다. 초대 메일을 수락해야 브랜치를 올릴 수 있다. 수락하기 전에도 로컬 작업은 시작해도 된다.
2. 자기 구글 계정으로 Gemini API 키를 만든다: https://aistudio.google.com/apikey
3. 저장소를 받고 `.env` 파일을 만든다. (Windows는 `cp` 대신 `copy`)

   ```bash
   git clone https://github.com/gobad820/KDT_AI_HACKATHON.git
   cd KDT_AI_HACKATHON
   cp .env.example .env
   ```

4. 편집기로 `.env`를 열고 `LLM_API_KEY=` 뒤에 자기 키를 붙인다. 나머지 줄은 그대로 둔다.
   **키는 Claude Code 채팅, 단체방, 커밋 어디에도 붙이지 않는다.**
5. 그 폴더에서 Claude Code를 켜고(`claude`), 아래에서 자기 이름의 "시작 문장"을 붙여 넣는다.

Claude Code는 폴더에 있는 `CLAUDE.md`를 스스로 읽는다. 브랜치 규칙, 금지 사항, 명령이 거기에 있어서 시작 문장이 짧아도 된다. 파이썬 환경(venv, 패키지 설치, pytest)도 Claude Code가 `CLAUDE.md`의 "명령"대로 만든다.

## 정상훈: 공식 계산기 대조

- 브랜치: `feat/sanghoon-calc-check`
- 마감: 계산 코드나 상수를 고쳐야 하면 **19:00까지 PR**. 대조표만 채우는 PR은 **23:00까지**.

할 일

1. [`docs/calc-rules.md` 8장](calc-rules.md#8-검증-계획) 표의 연봉 10개(2,600만~7,000만 원)를 공식 계산기로 직접 계산한다. Claude Code는 홈택스에 로그인할 수 없으므로 이 단계는 사람이 한다.
   - 4대보험: 4대사회보험 정보연계센터의 보험료 모의계산. 월 보수는 연봉 ÷ 12.
   - 결정세액: 홈택스 연말정산 모의계산. 총급여는 연봉 − 240만 원(비과세 식대), 부양가족 없음, 다른 공제 0.
   - 감면 입력란이 있으면 감면을 적용한 값도 적는다.
   - 3,300만~3,800만 원 구간부터 한다. 감면을 적용하면 계산 경로가 바뀌는 구간이다.
2. 계산한 값을 Claude Code에 알려 주고, 표의 "공식 계산기 값"과 "차이" 칸을 채운다. 어느 계산기를 언제 썼는지도 적는다.
3. 차이가 연 1,000원을 넘으면 원인(원 단위 처리, 계산 경로, 요율)을 찾는다.
   - `app/calc/`를 고치면 `scripts/calc_ref.py`와 결과가 같은지 확인한다.
   - 상수를 바꾸면 `docs/calc-rules.md`의 상수표도 같이 고친다.
4. 대조한 값을 테스트 기대값으로 추가한다. 소개서에 들어갈 검증 근거가 된다.

끝났다고 보는 기준: 8장 표 10행이 다 채워져 있고, 차이는 1,000원 이내이거나 이유가 적혀 있다. `python3 -m pytest`가 전부 통과한다.
